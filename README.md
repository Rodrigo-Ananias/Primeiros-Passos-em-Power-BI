Repositório criado para acompanhar a evolução das atividades obrigatórias do curso "Primeiros Passos em Power BI", ofertado pelo Santander Open Academy via plataforma DIO.me.

Para obter a certificação é necessário realizar os desafios de projetos de todos os seis (06) módulos do curso. Cada módulo tem,uma área de foco, sendo, respectivamente:

Módulo 01 - Introdução a Inteligência Aritifical e Agentes
	Ênfase em IA, Chatbots, Copilotos e Agentes de forma generalista. 
		Desafio do Projeto "Treinando uma IA de Aprendizagem: Explore o Poder do NotebookLM".

Módulo 02 - Fundamentos de BI 
  Ênfase nos conceitos introdutórios análise de dados em SQL, Power BI e fundamentos téoricos de análise de dados. 
   Desafio de projeto "Analisando dados de um Dashboard de Vendas no Power BI".

Módulo 03 - Visualização de Dados e Relatórios com Power BI. 
  Ênfase em fundamentos introdutórios de BI (kPIs e Métricas), trabalho manual com visualização de dados com Power BI.
    Desafio do Projeto "Criando um Relatório Gerencial de Vendas com Power BI".

Módulo 04 - Processamento de Dados com Power BI
  Ênfase na parte prática de ETL para o Power BI.
    Desafio de Projeto "Criando um Dashboard corporativo com integração com MySQL e Azure".
      OBS: Nessa atividade, tive um pequeno problema com a criação da conta no Azure e resolvi deixar o banco de dados local.
      Sendo assim, deixei um pequeno relatório sobre o que eu fiz e também o código utilizado para criação da base de dados.

Módulo 05 - Modelagem de Dados com Power BI
  Ênfase na utilização e criação de modelos dentro do Power BI e fórmulas DAX e Cálculos, mesclagem e acréscimo de dados.
    Desafio do Projeto (1) "Dashboard de Vendas com Power BI utilizando Star Schema".
    Desafio do Projeto (2) "Modelando um Dashboard de E-commerce com Power BI Utilizando Fórmulas DAX".

Módulo 06 - Data Analytics e Storytelling com Power BI
  Ênfase na utilização do Power BI para criação de relatórios interativos e instigantes ao público.
    Desafio do Projeto (1) "Criando um Dashboard Gerencial para Tomada de Decisões Com Power BI".
    Desafio do Projeto (2) "Criando um Relatório Vendas e Lucros com Data Analytics com Power BI".

Em suma, todos os materais utilizados para obter a certificação serão colocados nesse repositório. O repositório será dividido em módulos, contendo cada um o seu respectivo desafio de projeto.
